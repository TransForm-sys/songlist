# 布局改版方案：侧栏式（模仿 yybb.vsinger.ink）

> 目标：把现在的「单列居中列表」改成「全屏背景插画 + 一列歌单」的侧栏式布局，
> 歌单可切到左侧或右侧，桌面和手机都好看。
> 本文是**方案**，确认后再动手改。

---

| 区域 | 内容 | 我们的对应数据 |
| --- | --- | --- |

## 二、布局架构

### 三种形态

| 断点 | 形态 | 说明 |
| --- | --- | --- |
| ≥ 1024px | **侧栏态**：背景铺满 + 520px 侧栏（左/右可切） | 侧栏自身滚动，背景固定不动 |
| 768–1023px | 侧栏态但侧栏略窄（约 44%） | 同上 |
| < 768px | **单列态**：背景铺满 + 上方压暗遮罩，歌单占满宽度 | 筛选收进「筛选 +」弹层（贴底） |

### 关键 CSS 思路

```css
/* 背景层：固定、cover、不参与滚动 */
.stage-bg { position: fixed; inset: 0; background-size: cover; background-position: center top; z-index: 0; }
.stage-mask { position: fixed; inset: 0; z-index: 1; pointer-events: none;
  background: linear-gradient(90deg, rgba(0,0,0,.0) 40%, rgba(10,10,10,.72) 78%); }

/* 侧栏：右 */
.shell { position: relative; z-index: 2; min-height: 100dvh;
  display: grid; grid-template-columns: minmax(0, 1fr) 520px; }
.shell[data-side='left'] { grid-template-columns: 520px minmax(0, 1fr); }
.side { height: 100dvh; overflow: auto; display: flex; flex-direction: column; }
```

- 切换左右：`document.documentElement.dataset.side = 'left' | 'right'`，存 `localStorage`
  （键 `vtuber-song-list:side`），**首屏内联脚本**读一次防闪，和现在的主题一个套路。
- 移动端：`.shell` 变单列，`.side` 只保留内容、背景层给更强的暗色遮罩保证可读性。

## 三、视觉规范

| 元素 | 规格 |
| --- | --- |
| 歌名 | 26px / 字重 400 / 行高 1.25（移动端 22px） |
| 副行（歌手 · 语种 · 曲风） | 12–13px / 次级色 `/` 分隔 |
| 编号 | 11px 等宽 `tabular-nums`，弱色 |
| 行高 | 桌面 ≈ 76px，移动 ≈ 84px（虚拟滚动要用固定值） |
| 分隔线 | 1px `--line`，左右留 16px |
| 侧栏底色 | 极淡渐变遮罩（不加实体面板，保持"浮在图上"的感觉） |
| 主题 | 暗色优先；亮色下背景图降饱和 + 白色遮罩、文字转深色 |
| hover / 选中 | 行整体轻微提亮（`--hover`），和现在一致 |

## 四之二、移动端空间预算（2026-11-01 新增，按线上截图实测）

**问题**：手机上一个 960px 高的视口里，列表只占约 **46%**（约 5 行可见），头部+页脚吃掉 40%。

| 区域 | 现状占视口 | 目标 |
| --- | --- | --- |
| 标题行（标题/数量/简介/主题） | ~8% | 6%（字号再小一档；简介按钮改头像图标） |
| 公告 | ~12% | **2%（一行截断，点击展开）** |
| 搜索 | ~9% | 6%（和筛选同一行） |
| 筛选（三个下拉） | ~6% | 0（收进「筛选」弹层） |
| 表头（歌名/歌手） | ~5% | **0（移动端不显示）** |
| 列表 | ~46% | **70%+** |
| 页脚 | ~9% | 4%（提示行移动端隐藏；来源+ICP 合并一行小字） |

**六条措施与收益**（行 = 52px）

| # | 措施 | 省下 | 折合行数 |
| --- | --- | --- | --- |
| 1 | 公告默认 1 行 + 点击展开 | ~110px | +2 行 |
| 2 | 搜索 + 筛选合并成一行，筛选做成图标 → 底部弹层 | ~90px | +1.7 行 |
| 3 | 移动端去掉表头 | ~50px | +1 行 |
| 4 | 页脚压缩（隐藏"单击复制"提示、来源+ICP 并一行） | ~50px | +1 行 |
| 5 | **滚动时头部折叠**成一条 sticky 搜索条，向上滚恢复 | ~200px | +3.8 行 |
| 6 | 行高 52 → 50px（可读性边界，别再压） | ~26px | +0.5 行 |

前 4 项做完：**5 行 → 约 10 行**；加上第 5 项：**约 13~14 行**。

**技术细节**
- `.app` 的 `height: 100%` 换成 `height: 100dvh`（移动端地址栏收起/展开时不会跳），保留 `100%` 作为回退
- 列表保持"只让列表内部滚动"（现在是 `.list-viewport { flex:1; overflow-y:auto }` ✓ 结构没问题，是头部太高）
- 折叠头部用 `scroll` 监听 + `transform: translateY(-N)` 或直接切换紧凑类，避免布局抖动（只改 transform / height，不要改字体）
- 底部弹层复用现有 `.select-panel` 的移动端贴底样式（`position: fixed; bottom: 0; border-radius: 16px 16px 0 0`）
